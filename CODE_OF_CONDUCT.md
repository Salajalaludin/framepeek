# Code of Conduct

## Our commitment

We are committed to a welcoming, safe, and respectful community for everyone,
regardless of experience, identity, background, or ability.

## Expected behavior

- Be respectful and constructive.
- Discuss ideas and code without attacking people.
- Accept feedback gracefully and give others room to learn.
- Protect private information and report security-sensitive matters privately.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, and sustained disruption are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through an available
private GitHub contact channel. Do not include sensitive details in a public
Issue. If no private channel is available, use GitHub's blocking and abuse
reporting tools.

Maintainers may edit or remove contributions, issue warnings, temporarily
restrict participation, or permanently ban participants when needed. Reports
will be reviewed as promptly and confidentially as practical, and retaliation
against reporters is prohibited.

This Code of Conduct applies in project spaces and when someone publicly
represents the project.
